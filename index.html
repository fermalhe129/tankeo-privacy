Política de Privacidad de Tankeo

Última actualización: 2025

Tankeo es una aplicación diseñada para ayudar a los usuarios a administrar información relacionada con sus vehículos, incluyendo combustible, mantenimientos, documentos y alertas importantes.

Información recopilada

La aplicación puede recopilar la siguiente información:

  • Correo electrónico y nombre de usuario al iniciar sesión con Google.
  • Información de vehículos registrada por el usuario.
  • Registros de tanqueos, mantenimientos y documentos.
  • Información opcional de ubicación relacionada con estaciones de servicio.

Uso de la información

La información recopilada se utiliza únicamente para:

  • Sincronizar datos entre dispositivos.
  • Mostrar estadísticas y reportes dentro de la aplicación.
  • Generar alertas y recordatorios importantes.
  • Mejorar la experiencia del usuario.

Almacenamiento de datos

Tankeo utiliza almacenamiento local mediante SQLite y servicios de Firebase/Firestore para sincronización en la nube cuando el usuario inicia sesión con Google.

Compartición de datos

Tankeo no vende ni comparte información personal con terceros.

Seguridad

Se aplican medidas razonables de seguridad para proteger la información almacenada.

Permisos

La aplicación puede solicitar permisos para:

  • Notificaciones.
  • Acceso a imágenes o archivos.
  • Ubicación (si el usuario decide usar funciones relacionadas).

Eliminación de datos

El usuario puede eliminar sus datos desde la aplicación o desinstalando la app.

Contacto

Si tienes preguntas sobre esta política puedes contactar al desarrollador.
